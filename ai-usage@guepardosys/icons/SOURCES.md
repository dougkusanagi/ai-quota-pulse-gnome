# Provider artwork

The local files contain the real OpenAI knot and Claude burst paths, not hand-drawn approximations. Source mirrors:
- https://github.com/steipete/CodexBar/blob/main/Sources/CodexBar/Resources/ProviderIcon-codex.svg
- https://github.com/steipete/CodexBar/blob/main/Sources/CodexBar/Resources/ProviderIcon-claude.svg

Original paths are unchanged. `*-symbolic.svg` variants change monochrome fill only to allow GNOME's native symbolic recoloring (white top bar / dark popup / Claude terracotta). Artwork and trademarks belong to OpenAI and Anthropic respectively; the project's code license does not grant rights to the marks. No external image is downloaded at runtime.
