# AI Usage
<!-- impeccable:product-schema 1 -->
## Platform
Native GNOME Shell desktop extension.
## Stack
GJS ES modules, St, Clutter, Gio, GLib, libsoup 3; GTK4/libadwaita preferences.
## Users and purpose
People using multiple Codex and Claude subscription accounts who need to see real remaining quotas and reset times without leaving their desktop.
## Constraints
N independent profiles, existing CLI authentication, no credential copies, no browser scraping. GNOME 46–50 target. Portuguese UI. Native popup settings and account management.
## Brand commitments
Official local provider logos; compact panel with overlapping initials; translucent milky white glass, rounded popup, subtle separators and no nested cards. The supplied image establishes layout, while the text establishes the lighter material.
## Evidence
User brief and attached GNOME reference. Real quota values must come from provider responses.
